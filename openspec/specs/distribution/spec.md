# distribution Specification

## Purpose

Формирует самодостаточные сборки игры и установочные файлы для Linux и Windows, чтобы игроку не
требовались Python и зависимости, а релиз по тегу публиковал готовые артефакты. macOS-сборка
сохраняется в репозитории, но временно отключена в CI до стабилизации.

## Requirements

### Requirement: Самодостаточные сборки

Каждая платформенная сборка MUST запускать игру без установленного Python и MUST содержать
pygame и все данные, нужные для процедурной сцены. Сборка MUST поддерживать флаг `--version`,
который печатает версию и завершается без открытия окна.

#### Scenario: Запуск без Python
- **WHEN** собранный файл запускается на машине без Python
- **THEN** игра запускается
- **AND** окно игры открывается без ошибок импорта

#### Scenario: Версия собранной игры
- **WHEN** собранный файл запускается с флагом `--version`
- **THEN** печатается версия игры
- **AND** окно не открывается

### Requirement: Linux-пакеты deb и rpm

Для Linux MUST собираться пакеты `.deb` и `.rpm`. Установка пакета MUST класть исполняемый
файл в `/usr/bin/albatross`, добавлять ярлык в меню приложений и иконку; удаление пакета MUST
удалять установленные файлы.

#### Scenario: Установка deb-пакета
- **WHEN** пользователь устанавливает `.deb` пакет
- **THEN** команда `albatross` доступна в `PATH`
- **AND** в меню приложений появляется ярлык игры
- **AND** иконка установлена в тему hicolor

#### Scenario: Установка rpm-пакета
- **WHEN** пользователь устанавливает `.rpm` пакет
- **THEN** команда `albatross` доступна в `PATH`
- **AND** ярлык и иконка установлены в системные каталоги

### Requirement: Windows-установщик

Для Windows MUST собираться установщик `.exe`. Установщик MUST ставить игру в каталог
программ, создавать ярлык в меню «Пуск» и предоставлять штатное удаление.

#### Scenario: Установка на Windows
- **WHEN** пользователь запускает установщик
- **THEN** игра устанавливается в каталог программы
- **AND** в меню «Пуск» появляется ярлык Albatross
- **AND** в списке установленных приложений есть запись для удаления

### Requirement: Сборка в CI на Linux и Windows

CI MUST собирать установочные файлы на `ubuntu-latest` и `windows-latest` при push в основную
ветку и при создании тега `v*`. Перед упаковкой CI MUST прогнать тесты; падение тестов MUST
блокировать публикацию артефактов.

#### Scenario: Успешная сборка
- **WHEN** изменения попадают в основную ветку
- **THEN** CI запускает тесты на Linux и Windows
- **AND** собирает установочные файлы для Linux и Windows
- **AND** выкладывает их как артефакты workflow

#### Scenario: Провал тестов
- **WHEN** тесты падают
- **THEN** установочные файлы не публикуются
- **AND** релиз по тегу не создаётся

### Requirement: Релиз по тегу

При push тега вида `v*` CI MUST создавать GitHub Release с прикреплёнными `.deb`, `.rpm` и
Windows-установщиком. Имена файлов MUST содержать версию игры. macOS-образ MAY быть добавлен
позже отдельным изменением.

#### Scenario: Публикация релиза
- **WHEN** в репозиторий отправлен тег `v0.1.0`
- **THEN** создаётся GitHub Release `v0.1.0`
- **AND** к релизу прикреплены deb, rpm и exe
- **AND** имена файлов содержат `0.1.0`
