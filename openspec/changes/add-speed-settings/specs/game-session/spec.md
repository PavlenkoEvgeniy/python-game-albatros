# game-session Specification

## ADDED Requirements

### Requirement: Настройка скорости игры

Игра MUST предоставлять именованные пресеты скорости, переключаемые циклически одной
клавишей (S). Переключение MUST применяться только вне активного забега: в меню и на
экране проигрыша. Попытка изменить скорость во время полёта или паузы MUST игнорироваться
без изменения физики текущего забега. Выбранный пресет MUST применяться к следующему
забегу и сохраняться между забегами в рамках одного запуска игры; между запусками игры
MUST использоваться пресет по умолчанию.

#### Scenario: Переключение пресета в меню
- **WHEN** игрок нажимает S в меню
- **THEN** пресет скорости переключается на следующий по циклу
- **AND** следующий забег стартует с выбранным темпом

#### Scenario: Игнорирование во время полёта
- **WHEN** игрок нажимает S во время полёта или паузы
- **THEN** пресет не меняется
- **AND** физика текущего забега остаётся неизменной

#### Scenario: Смена скорости на экране проигрыша
- **WHEN** игрок нажимает S на экране проигрыша
- **THEN** пресет переключается
- **AND** рестарт начинается с новым темпом
