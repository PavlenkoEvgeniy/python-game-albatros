# Proposal

## Why

Нужна законченная небольшая аркада про альбатроса: игрок стартует с горы, планирует вниз и
должен растянуть полёт как можно дальше, расходуя ограниченный запас сил на взмахи. Сейчас
проекта нет — есть только пустой каталог и инициализированный OpenSpec. Ценность — играбельный
вертикальный срез с честной физикой, аккуратным визуальным стилем и воспроизводимой сборкой.

## What Changes

- Новый Python-проект `albatross` на `pygame-ce` с запуском одной командой и упаковкой через
  `uv`.
- Полёт: старт с горы, постоянное снижение при планировании, взмах по пробелу/клику даёт
  подъём и тратит силы; при нулевых силах взмахи недоступны; касание земли завершает забег.
- Счёт: пройденная дистанция в метрах во время полёта; рекорд сохраняется между запусками.
- Оболочка игры: стартовый экран, пауза, экран проигрыша, рестарт без перезапуска процесса.
- Подача: процедурная векторная графика (небо, слои гор, птица, HUD) без внешних ассетов;
  процедурный звук взмаха и ветра с безопасным отключением; переключение языка RU/EN.
- Инженерная база: чистый домен без pygame, фиксированный шаг симуляции, детерминированный
  RNG, `ruff`, `mypy --strict`, `pytest` + `hypothesis`, покрытие домена 100%, GitHub Actions.
- Дистрибуция: приватный GitHub-репозиторий, CI-сборка на Linux/Windows/macOS, установщики
  `.deb`/`.rpm`, Windows `.exe`, macOS `.dmg`; релиз по тегу `v*` с прикреплёнными файлами.

Вне объёма первой версии: препятствия, хищники, бонусы, турбулентность/термики, уровни,
мультиплеер, таблицы лидеров, внешние художественные и звуковые ассеты, мобильные сборки.

## Capabilities

### New Capabilities

- `flight`: физика полёта — старт с горы, планирование со снижением, взмахи, запас сил,
  касание земли и измерение пройденной дистанции.
- `run-scoring`: сохранение лучшего результата между запусками и устойчивость файла рекорда.
- `game-session`: жизненный цикл забега (меню → полёт → пауза → проигрыш → рестарт) и
  управление с клавиатуры и мыши.
- `presentation`: векторный рендер, HUD, параллакс, локализация RU/EN и процедурный звук.
- `distribution`: самодостаточные сборки и установочные файлы для Linux, Windows и macOS,
  CI-сборка на трёх ОС и публикация релиза по тегу.

### Modified Capabilities

Нет — проект новый, существующих спек нет.

## Impact

- Новый код: `src/albatross/` (домен, рендер, ввод, звук), `tests/`, `pyproject.toml`,
  `main.py`, `README.md`, `.github/workflows/ci.yml`, `.github/workflows/build.yml`.
- Упаковка: `packaging/linux/` (deb/rpm, desktop, иконка), `packaging/windows/albatross.iss`,
  `packaging/macos/build_dmg.sh`, `packaging/icons/`; PyInstaller как build-зависимость.
- Зависимости: `pygame-ce` (runtime), `pytest`, `pytest-cov`, `hypothesis`, `ruff`, `mypy`,
  `pyinstaller` (dev/build). Внешних ассетов игры нет; иконки генерируются из её графики.
- Побочные эффекты: файл рекорда в платформенном каталоге (`XDG_DATA_HOME` / `%LOCALAPPDATA%`),
  инициализация аудиоустройства (с безопасным fallback), окно pygame.
- GitHub: приватный репозиторий `PavlenkoEvgeniy/python-game-albatros`, релизы по тегам.
- Совместимость: Python 3.12+, проверка на 3.14; Linux — основная платформа, Windows/macOS
  поддерживаются за счёт кроссплатформенного pygame-ce и отдельных установщиков.
